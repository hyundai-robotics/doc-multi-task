# 2.6.2 从子任务中选择

在子任务中选择程序时，仅会新选择该子任务中的程序。

|     **任务类型**     |      **操作内容**                                |
| :-------------------: | --------------------------------------------------------- |
|       主任务         | 无变化                                                 |
|       子任务         | 更改程序编号 <br> 清除步骤和功能编号 |
