# 2.6.2 서브태스크에서 선택

서브태스크에서 프로그램 선택 시에는 해당 서브태스크의 프로그램만 새롭게 선택됩니다. 


|     **태스크 종류**    | 　　 　　**동작 내용**                                |
| :--------------------: | ---------------------------------------------------- |
|       메인태스크        | 변동 사항 없음                                        |
|       서브태스크        | 프로그램 번호 변경 <br> 스텝번호, 펑션번호 클리어       |
