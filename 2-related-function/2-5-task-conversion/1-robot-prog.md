# 2.5.1 机器人程序

任务切换可以通过以下表中所示的按键操作实现。任务切换仅在已创建的任务之间进行。 

|            **操作**            |    **描述**         |
| :-----------------------------: | ------------------ |
|       `[CTRL]+[->]` 键      | 切换到下一个任务          |
|       `[CTRL]+[<-]` 键      | 切换到上一个任务      |
