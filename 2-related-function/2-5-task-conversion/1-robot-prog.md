# 2.5.1 机器人程序

可以使用下面表中所示的键操作进行任务切换。任务切换仅在创建的任务之间可能。

|            **操作**            |    **描述**         |
| :----------------------------: | ------------------ |
|       `[CTRL]+[->]` 键      | 切换到下一个任务      |
|       `[CTRL]+[<-]` 键      | 切换到上一个任务      |
