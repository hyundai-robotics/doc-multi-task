# 2.5.2 输出信号分配

可以使用以下菜单选择程序为每个任务分配输出信号。即使当前没有分配子任务，也可以这样做。

您可以通过使用 `[F2: 系统] - 2: 控制参数 - 2: 输入/输出信号设置 - 4: 输出信号分配 ([F2: System] - 2: Control parameter - 2: Input/Output signal setting - 4: Output signal assign)` 屏幕上的 [上一任务]/[下一任务] 按钮为每个任务设置输出信号。
