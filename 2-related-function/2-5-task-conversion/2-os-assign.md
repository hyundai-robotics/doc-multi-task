# 2.5.2 출력 신호 할당

태스크 별로 출력 신호 할당은 다음의 메뉴 선택 절차로 가능합니다. 현재 서브태스크가 할당되어 있지 않은 상태에서도 설정이 가능합니다. 
 
`[F2: 시스템] - 2: 제어 파라미터 - 2:입출력 신호 설정 - 4:출력 신호 할당` 화면에서 `[이전태스크]`/`[다음 태스크]` 버튼에 의해 태스크별 출력 신호를 설정할 수 있습니다.
